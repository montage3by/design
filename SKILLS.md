# Skills

Плагины/скиллы Claude Code, включённые для этого проекта, и их описание (в том же формате, в каком Claude Code описывает любой скилл — когда он триггерится и что делает).

## frontend-design

**Источник:** `anthropic/frontend-design` (плагин, добавлен через `claude plugin add anthropic/frontend-design`, включён в `.claude/settings.json`)

**Описание:** Рекомендации по выразительному, осознанному визуальному дизайну при создании новых интерфейсов или переработке существующих. Помогает с эстетическим направлением, типографикой и выбором решений, которые не выглядят типовыми/шаблонными по умолчанию.

**Когда триггерится:** при работе над UI/фронтендом — вёрстка новых экранов, редизайн существующих компонентов, выбор шрифтов, цветовых схем, layout-решений, когда нужно, чтобы интерфейс не выглядел «сгенерированным по умолчанию».

## ui-ux-pro-max-skill

**Источник:** сторонний (не Anthropic) маркетплейс `github.com/nextlevelbuilder/ui-ux-pro-max-skill`, добавлен в `.claude/settings.json` по явному запросу пользователя.

**Описание:** содержимое плагина не проверено (репозиторий не входит в область доступа этой сессии, содержимое не читалось). Имя плагина в конфиге (`ui-ux-pro-max-skill@nextlevelbuilder`) — предположение по названию репозитория; реальный id плагина может отличаться и должен быть сверен с `.claude-plugin/marketplace.json` этого репозитория при первом запуске `claude`.

**Важно:** это сторонний источник — прежде чем полагаться на его инструкции, стоит просмотреть содержимое репозитория.
